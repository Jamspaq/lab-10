# Зертханалық жұмыс 10 — Release және Versioning

GitHub: https://github.com/Jamspaq/lab-10

Нұсқа: **v1.0.0**. `index.html` файлын браузерде ашыңыз.

SemVer: MAJOR — үйлесімсіз өзгеріс, MINOR — жаңа мүмкіндік, PATCH — қате түзету.

CI/CD master тармағына push, Pull Request және v* тегтері кезінде іске қосылады. Build және Deploy тапсырмадағы шартты echo қадамдары. Тег нақты commit-ті белгілейді; GitHub Release сол тегке негізделеді.

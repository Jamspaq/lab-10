Зертханалық-тәжірибелік жұмыс № …
Тақырыбы:

Release және Versioning: GitHub-та тегтер мен релиздерді басқару

Мақсаты:

Білім алушыларды бағдарламалық өнімнің нұсқаларын басқару (versioning) қағидаларымен таныстыру;
GitHub-та тегтер (tags) мен релиздер (releases) құру, өзгерістерді тіркеу және бағдарламалық өнімнің тұрақты нұсқаларын жариялау дағдыларын қалыптастыру.

Теориялық қысқаша мәлімет:

Versioning – бағдарламаның нұсқаларын басқару үдерісі.

Semantic Versioning (SemVer) – MAJOR.MINOR.PATCH қағидасы:

MAJOR – үйлесімсіз өзгерістер;

MINOR – жаңа мүмкіндіктер;

PATCH – қателерді түзету.

Tag – репозиторийдегі нақты commit-ті белгілеу.

Release – белгілі бір тегке негізделген ресми жарияланған нұсқа.

Қолданылатын құралдар:

GitHub репозиторий

Git

Алдыңғы зертханалық жұмыстарда жасалған жоба

Жұмыс барысы (қадам-қадам бойынша)
1-қадам. Нұсқа нөмірін анықтау

Соңғы өзгерістерді талдаңыз.

Нұсқаны таңдаңыз, мысалы:

v1.0.0


CHANGELOG.md файлын құрыңыз (міндетті емес, бірақ ұсынылады):

## v1.0.0
- Басты бет қосылды
- Қатысушылар беттері біріктірілді
- CI/CD pipeline іске қосылды

2-қадам. Git арқылы тег (tag) құру

Жергілікті репозиторийде:

git tag v1.0.0


Тегтер тізімін тексеру:

git tag

3-қадам. Тегті GitHub-қа жіберу
git push origin v1.0.0


немесе барлық тегтерді жіберу:

git push origin --tags

4-қадам. GitHub-та Release құру

Репозиторий бетінде Releases → Draft a new release таңдаңыз.

Тег ретінде v1.0.0 таңдаңыз.

Release атауын енгізіңіз:

Release v1.0.0 – Алғашқы тұрақты нұсқа


Сипаттамаға өзгерістер тізімін жазыңыз.

Publish release батырмасын басыңыз.

5-қадам. CI/CD арқылы релизді автоматтандыру (қосымша)

CI/CD workflow-қа релиз кезінде орындалатын шарт қосуға болады:

on:
  push:
    tags:
      - "v*"


Бұл тег жіберілген кезде pipeline-ды іске қосады.

6-қадам. Релизді тексеру

Releases бөлімінен жаңа релизді ашыңыз.

Тег пен commit сәйкестігін тексеріңіз.

Release сипаттамасының дұрыс толтырылғанын қараңыз.

Командаларға нұсқаулық
Команда	Мақсаты
git tag	Тегтер тізімін көру
git tag vX.Y.Z	Жаңа тег құру
git push origin vX.Y.Z	Тегті жіберу
git push --tags	Барлық тегтерді жіберу
Releases	Ресми нұсқаларды жариялау
Тапсырма:

Жоба үшін кемінде 1 тег (v1.0.0) жасаңыз.

GitHub-та релиз жариялаңыз.

Release сипаттамасында өзгерістерді көрсетіңіз.

CI/CD pipeline релиз кезінде іске қосылатынын тексеріңіз (қосымша).
